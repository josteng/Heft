A way to create a vault from scratch, and fixes to typing, tables and the file tree.

## Added

- **File ▸ New Vault** creates a new vault: a folder with one `Start Here` note in it, opened on that note. The welcome screen offers it too.

## Fixed

- Promoting `*word*` to `**bold**` by hand works, and so does demoting it back. A marker typed in front of one already there is inserted rather than stepped over, a marker typed after a closing one no longer leaves three, and backspace between two markers takes one rather than both.
- A space typed at the end of a table cell stays where you typed it, and the caret follows it.
- Two clicks in a table cell take the word, three take the cell.
- Opening a folder no longer takes the highlight off the note you are editing. The folder carries a fainter tint instead, marking it as what ⌘C, ⌘V and ⌘⌫ would act on, and that goes out as soon as the keyboard goes back to the note.
- The caret on a blank line stands where the first character will land, at the height of the font. It used to sit above that point, and to draw heading-tall on the empty line under a heading.
- **⌘L** (Toggle Checkbox) no longer lags behind the keys when it is held down.

## Under the hood

- The test suite no longer fails at random on a busy machine. Two waits measured a wall clock, which a loaded machine can spend without ever giving the test its turn; they count attempts instead.
