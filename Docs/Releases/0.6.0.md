The editor catches your spelling and grammar as you type, the Recent list reads like your notes instead of a folder listing, Siri can write into the vault, and a note can be dragged out of every list in Heft.

## Added

- **Spelling and grammar are checked as you write.** Code, maths, frontmatter, tags and a link's destination are left alone. Three switches in Settings → Typing: Check Spelling, Check Grammar With Spelling, and Correct Spelling Automatically.
- **`heft spell <vault> [note]`** reports the same misspellings and grammar notes to an agent, with `--no-grammar`, `--limit` and `--json`.
- **The Recent list shows what is in each note**: its date, first line and folder, grouped under Today, Yesterday, Previous 7 Days and by month. Order it by last edit or by last opening, in the list's own menu or in Settings, and keep the compact rows if you prefer them.
- **Siri can create notes, add to them, find them and open them**, today's daily note included.
- **Right-clicking a note or folder offers Ask Siri about that one**, rather than about whatever is on screen (macOS 27).
- **Notes drag out of every list** — Recent, tags, search results, ⌘O (Quick Open) and ⌘P (Command Palette) — and the window's title bar carries the open note, so it drags into the Finder or a terminal.
- **The folder name in the title bar drags out as the window's root folder**, for dropping into an agent's prompt or a terminal.
- **That folder menu lists the folders you focused on lately**, so switching between a few takes one click, and it gains Copy Absolute Path and Reveal in Finder.
- **⌘O takes a path as well as a name**, vault-relative or absolute, quoted, escaped or a `file://` URL, and puts the note it names first.
- **⌘P reaches the rest of the app**: Quick Open, vault search, Find in note, the six formatting commands, new note, new vault, save, Settings and agent access.
- **Clicking a picture in a presentation shows it across the screen**, scaled up to fill it, and the next key or click puts it away.
- **Filtering the file tree finds folders**, and clicking one opens the tree down to it.
- **Show the Entire Vault is in the file tree's own menu**, where a focused window undoes its focus.

## Changed

- **⌘O lists the focused folder's notes**, with the same toggle for the whole vault that ⌘⇧F (Search the Vault) has. A pasted path ignores the scope.
- **Presentations scale inline code, maths and the bars beside headings** with the rest of the slide.
- **Go to Path is gone**: ⌘O does its job, and shows the match before you commit to it.
- **Set Up Agent Access is disabled while the vault's guides are current**, in the File menu and the palette alike.
- The history keeps **100 openings instead of 40**, and the ones from before Heft recorded times sit under Earlier.

## Fixed

- An embedded picture **redraws when you export the file again**, instead of keeping the version from when the note was opened.
- The presentation progress bar **moves smoothly**, including while ← and → are held down, and slides change at once when the arrows come faster than the fade.
- Siri's rewrite **stays out of a note you open while it is working**, and is no longer animated over it.
- A name you are renaming **shows its cursor and selection**, instead of losing them in the row's highlight.
- The Tags list **names the folder it looked in** when a focused window has no tags, rather than saying the vault has none.
- The folder menu in the title bar **stays beside the traffic lights** when the sidebar is narrow, instead of dropping into the overflow menu and letting the sidebar button slide across.
- The sidebar's filter field **stays the same width** in Files, Recent and Tags.
