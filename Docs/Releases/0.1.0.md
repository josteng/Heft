The first release of Heft: a native Mac app for Markdown notes that stay plain files in a folder you own, with a `heft` command built for the coding agent you already use.

## Install

```bash
brew install --cask josteng/tap/heft
```

Requires macOS 26 on Apple Silicon. The app is signed and notarised.

## What is in it

- One editing surface: the Markdown stays in the file, the markup hides until the caret reaches it.
- Callouts, tables, task lists, LaTeX, syntax-highlighted code, wikilinks and backlinks, tags, daily notes, capture from Spotlight, PDF export.
- A Vim mode.
- The `heft` command: a resolved index of the vault to read from, and proposals an agent submits for you to review and accept change by change. `heft help` lists every verb.
- Opens an Obsidian vault unmodified, including its `.obsidian/` settings.

## Known gaps

No iOS app yet, and no plugin system. See the README for the rest.
