Polish after the first release, from a day of clicking through the app.

## Added

- Settings ▸ Capture: which vault a capture made from Spotlight goes to when you have more than one, the one opened last or always the same; and which note in a vault is the inbox, per vault. The "Capture to Inbox" and "Open Inbox" shortcuts follow both, a missing folder is created on the first capture, and the pane carries the daily-log marker with a Copy button.
- Settings ▸ Startup: which vault a start with nothing to restore opens, the one opened last or always the same.
- Open Inbox, in the File menu and the palette next to today's note. It creates the inbox note when the vault has none.
- `heft config` names today's note by the vault's own rule and says whether it exists, so an agent asked to add to it neither applies the date format itself nor creates it by asking.
- `heft propose --move` accepts a move into a path that another pending move vacates, so a numbered series can be shifted in one round; the review centre applies it only once the path is free. And a proposal can create a note at a path that was read and then moved away.

## Changed

- Every settings pane is laid out the same way, as System Settings does it: controls in a card, what each does under its name, group titles above. Appearance and Typing were rebuilt, the Typing pane stops at 760 points and scrolls instead of taking the window to the screen's edge, and the labels say what they mean, with color spelled one way.
- Vim mode starts off, everywhere, until you switch it on in Settings or with the new "Toggle Vim mode" command in the palette (⌘P). It used to follow the vault's Obsidian setting silently, which switched modal editing on without a word on a fresh Mac.
- The offer to set a vault up for agents moved from a banner over the note into the review centre at the top of the sidebar, where it fits any window width, with a question mark that explains what gets written and how to start an agent there.

## Removed

- The in-app Capture to Inbox sheet (⇧⌘I). Heft's "Capture to Inbox" shortcut does the same from Spotlight, anywhere, Heft included, so the app keeps one path.

## Fixed

- A vault without agent instructions no longer opens a window taller than the screen that cannot be shrunk until Not Now is clicked.
- Set Up now refreshes the sidebar, so CLAUDE.md and AGENTS.md appear as soon as they are written.
- A new empty note no longer starts with a widget left over from the note before it.
- A note just named in the sidebar takes the caret, so you can write right away.
- Two tags side by side no longer touch.
- The new-note button beside the filter field has the same fill as the field.

## Under the hood

- The test suite runs in 41 seconds instead of 97: the Neovim oracle asks a batch of cases per process, at background priority so the timing checks keep their cores.
