Links reach into a note, the chrome settles into Liquid Glass, and the editing surface loses a run of long-standing rough edges.

## Added

- **A link can name a section.** `[[Note#Heading]]` opens the note and lands on that heading, `[[Note#^block]]` on a single line, and `[[#Heading]]` jumps inside the note already open. Capitalisation need not match, and a heading that no longer exists opens the note rather than refusing.

## Changed

- The **sidebar header**, the **completion menu** and the **window chrome** are drawn in Liquid Glass, and the plain chrome controls light under the pointer.
- **Quick Open, the command palette and vault search** are translucent, so the note stays visible behind them.
- The **sidebar switch** is a real segmented control again, drawn as tabs in a capsule and kept neutral instead of taking the accent colour.
- **Quick Open and the command palette are one size.** Vault search stays larger.
- The **proposal and review banners** are set in from the window's edges.

## Fixed

- A note longer than the window **opens with its first line visible**, not scrolled up behind the toolbar.
- **Extra spaces after a list marker move the text, not the bullet.** Typing one used to drag the bullet left and leave the text where it stood.
- **Tab and Shift-Tab move a list item one level** without rewriting the rest of its indentation, and undoing that puts the caret back where it was.
- A `---` rule written under an HTML comment **stays a rule** instead of turning the comment into a heading.
- Each window's editor keeps its own styling, so a **second window no longer disturbs the first**.
- The sidebar **highlights the note that is open**, wherever you opened it from, and **Reveal in Sidebar** draws its highlight again.
- **Arrow keys scroll the command palette**, which they never did, and elsewhere the list moves only once the selection reaches the edge.
